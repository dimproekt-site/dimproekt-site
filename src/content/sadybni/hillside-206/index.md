## Одноповерховий будинок із цокольним поверхом для ділянки з рельєфом
Цей проєкт створено для ділянки зі складним рельєфом: перепад висот використано як перевагу. Головний вхід розташований на рівні першого поверху, а в цоколі, що відкривається на нижчий бік ділянки, з'являється повноцінний поверх для гаража та господарських приміщень. Загальна площа 206,83 м².
Перший поверх — житловий. Вхід через ганок веде в передпокій із вбудованою шафою. Центральний хол поєднує всі кімнати. Вітальня та їдальня (24,24 м²) разом із кухнею утворюють єдиний світлий простір для всієї родини. Спальна зона включає спальню господарів із шафою-купе та дві дитячі кімнати з робочими місцями для навчання. Передбачено ванну кімнату та окремий санвузол. Звідси ж ведуть сходи на горище, яке можна використовувати для зберігання.
Цокольний поверх — господарський. Внутрішні сходи з'єднують його з житловою частиною, тож у гараж чи комору можна спуститися, не виходячи надвір. Тут розташовані:
- просторий гараж (41,81 м²) із запасом місця для зберігання інструменту, шин та інвентарю;
- котельня з твердопаливним котлом, що забезпечує незалежне від газу опалення;
- льох для зберігання овочів і консервації;
- комора;
- господарська кімната з пральною машиною та місцем для прасування.
Уся «господарка» зібрана внизу й не перетинається з житловою зоною.
Архітектура поєднує сучасність і традиційне житло. Світлі оштукатурені стіни контрастують із облицюванням цоколя натуральним каменем, яке візуально «закріплює» будинок на схилі. Чотирисхилий дах із сучасним покриттям і широкі звиси з дерев'яною підшивкою додають силуету затишку. Перед головним входом облаштована велика тераса з дерев'яним огородженням, місце для відпочинку всією родиною.
Цей проєкт поєднує комфорт, естетику та практичність і стане вдалим рішенням для сім'ї, яка будується на непростій ділянці та хоче мати все необхідне для заміського життя.
